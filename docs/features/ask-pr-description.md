First Mate 2026-11-05 22:54Z. A left drag or visible Ask action captures a
canonical Notion card, retains a personal Desk question, and uses the existing
First Mate inbox through the authenticated outbound puller for a correlated
answer. Answer navigation reveals and highlights the original card. Known
capture failures remain visible and retryable.

mobile. Existing Inspector actions and card click semantics are preserved.
