# Ask First Mate: slice 1

This is slice 1: one work card, text, Sent/Delivered/Answered, approved by
First Mate 2026-11-05 22:54Z. A left drag or visible Ask action captures a
canonical Notion card, retains a personal Desk question, and uses the existing
First Mate inbox through the authenticated outbound puller for a correlated
answer. Answer navigation reveals and highlights the original card. Known
capture failures remain visible and retryable.

The [feature contract](ask.md) owns the current inbox layout and ordering.
Existing Inspector actions and card click semantics are preserved.

See the [feature contract's follow-up slices](ask.md#follow-up-slices) for
remaining scope and physical-device verification requirements.

Reviewable PR only; no auto-merge or deploy is authorized. The outer pipeline
supplies authoritative validation and CI results.
